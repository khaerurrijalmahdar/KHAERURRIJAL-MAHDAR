## 🧠 Deskripsi Umum

Aplikasi berbasis web untuk **mendeteksi dan membaca angka pada meteran air PDAM secara otomatis** menggunakan **YOLOv8** dan **Flask**.  
Dikembangkan sebagai bagian dari **tugas akhir (skripsi)** untuk mendukung **otomatisasi dan transformasi digital** dalam proses pencatatan meteran PDAM.

Aplikasi ini menggabungkan teknologi **computer vision**, **machine learning**, dan **pengelolaan basis data** untuk membantu proses pencatatan meteran air menjadi lebih **efisien, cepat, dan akurat**.

---

## 🚀 Fitur Utama

- 📸 **Deteksi otomatis angka** pada citra meteran air menggunakan YOLOv8.  
- 🌐 **Antarmuka web (Flask)** untuk unggah gambar dan kelola data pelanggan.  
- 🧾 **Perhitungan otomatis tagihan air** berdasarkan pembacaan sebelumnya.  
- 🗃️ **Database SQLite** terintegrasi dengan SQLAlchemy ORM.  
- 🧾 **Ekspor laporan PDF dan CSV** lengkap dengan QR Code.  
- 👁️ **Fitur verifikasi manual** sebelum data disimpan.
